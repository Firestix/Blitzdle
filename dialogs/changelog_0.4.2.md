## v0.4.2
### 10/27/2026
#### New gameplay features
- Added guesses counter to the keyboard UI
- Added accuracy counter to the keyboard UI (disabled by default, enable it in settings)
- Added popup notifications when a word is solved
#### Settings dialog update
- Added the following settings to the settings dialog:
  - Set app appearance to light mode, dark mode, or use the device's theme
  - Change timer appearance or disable timer
  - Enable/disable guess count UI
  - Enable/disable accuracy UI
  - Enable/disable popup notification UI
  - Enable/disable text link for share texts
#### Other changes/fixes
- Added emoji icons to main menu UI and buttons
- Updated UI styling for custom game and settings dialogs
- Added emoji icons to end game dialog
- Fixed daily expert and random expert shortcut buttons
